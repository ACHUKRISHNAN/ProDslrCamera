# How to Open and Run ProDSLRCamera in Android Studio (No Coding Needed)

1. **Unzip** `ProDSLRCamera.zip` onto your computer (for example, on your Desktop).
2. Open **Android Studio**.
3. Click **Open** (or **File -> Open**).
4. Select the unzipped **`ProDSLRCamera`** folder and click **OK**.
5. Wait 1–3 minutes while Android Studio automatically downloads the Gradle dependencies (you will see a progress bar at the bottom right).
6. Connect your Android phone via USB (with **USB Debugging** enabled in Developer Options) and press the green **Run (Play ▶)** button at the top of Android Studio.
